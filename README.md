# Muse Atlas

A personal fan encyclopedia of the English rock band **Muse**: all ten studio albums with tracklists and stories, every major single, band history, curiosities and a quiz.

## Features

- **Albums:** tracklists, producers, release dates, UK chart peaks and background stories for all 10 studio albums, from *Showbiz* (1999) to *The Wow! Signal* (2026)
- **Singles:** searchable timeline of the band's singles, filterable by album
- **The Band:** member profiles, a 1994–2026 timeline and a listening guide
- **Curiosities:** 20 trivia facts
- **Quiz:** 14 questions to test yourself
- Tick off songs as you learn them; drag images onto album tiles and member cards to add your own covers and photos (saved in your browser only)
- A YouTube button next to every song

## Running it

It's a single self-contained file. Open `index.html` in any browser, or enable GitHub Pages for this repo (Settings → Pages → Deploy from branch → `main` / root).
